# Neural Amplifier v0.1.0

The first public release of Neural Amplifier establishes the tested, platform-neutral
orchestrator for connecting an LLM or interactive agent to Sid Meier's Alpha Centauri.

Highlights:

- A validated decision contract shared by game adapters and agent clients.
- Scripted, hosted-model, and interactive-agent brain modes.
- Bulk turn planning, directives, deferrals, replay, and evaluation reporting.
- A read-only dashboard for decisions, strategy adherence, grounding, and run coverage.
- Python wheel and source distribution for the `neural-amplifier` command-line tool.

Neural Amplifier remains pre-alpha: interfaces and saved run formats may change before 1.0.
