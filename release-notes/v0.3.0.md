# Neural Amplifier v0.3.0

This release makes knowledge retrieval failures visible before a model run
starts. An LLM run now refuses to begin without its retrieved context and
reports why retrieval failed, instead of playing blind. An explicit opt-in
still allows a blind run, and the play preflight warns rather than blocks
in that mode.

Telemetry now records which model answered each request and what it cost.
The repository also adds the first cross-model evaluation, run on
byte-identical prompts, with its published results under `evals/`.

The release provides the platform-neutral Python orchestrator as a wheel and
source distribution, with checksums. Game adapters and copyrighted game assets
are not bundled. Neural Amplifier remains pre-alpha; interfaces and saved-run
formats may change before 1.0.
