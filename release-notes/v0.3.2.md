# Neural Amplifier v0.3.2

This patch makes the package report its real version. `neural_amplifier.__version__`
and the CLI now read the installed distribution's metadata. Previously they
returned a hardcoded `0.1.0` regardless of the installed release.

The release provides the platform-neutral Python orchestrator as a wheel and
source distribution, with checksums. Game adapters and copyrighted game assets
are not bundled. Neural Amplifier remains pre-alpha.
