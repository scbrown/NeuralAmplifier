# Neural Amplifier v0.2.0

This release adds advisory Jev observations and a pinned grounding-ranking
evaluation arm. Advisory observations record context; they do not change the
engine's authority to validate legal actions.

It also includes fixes since v0.1.0 for classifying a busy input channel,
dashboard JavaScript newline handling, bounded hosted-model retries, and test
adapter lifetimes. The license is plain MIT with the scope note in NOTICE.

The release provides the platform-neutral Python orchestrator as a wheel and
source distribution, with checksums. Game adapters and copyrighted game assets
are not bundled. Neural Amplifier remains pre-alpha; interfaces and saved-run
formats may change before 1.0.
