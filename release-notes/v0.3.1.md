# Neural Amplifier v0.3.1

This patch isolates Claude Code decisions from the host environment. Each
decision runs in a fresh temporary working directory with project and user
context disabled, so unrelated host instructions do not enter the decision.
The existing legal-action validation and safe fallback remain in place.

The release also includes the recorded context-isolation evaluation and
regression coverage for the isolated execution path.

The release provides the platform-neutral Python orchestrator as a wheel and
source distribution, with checksums. Game adapters and copyrighted game assets
are not bundled. Neural Amplifier remains pre-alpha.
